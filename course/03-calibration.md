# 第三章：标定中心

> **本章目标**：学会使用标定中心的三大功能区——整机维护（升降/头部点动）、关节标定（零位采集与应用）、夹爪调试（端点标定与开合控制）。
> **涉及文件**：`src/xr_arm_console/xr_arm_console/app.py`（标定接口）

## 页面结构

「标定中心」页从上到下三个功能区：**整机维护**（升降/头部）、**关节标定**、**双臂标定表 + 选中关节面板**。所有会真实运动的按钮都要求现场安全确认，属于受控操作。

## 整机维护：升降与头部点动

顶部「WHOLE ROBOT · 整机维护·升降/头部」卡片提供整机点动按钮：

![标定中心：整机维护按钮区与左右臂标定表](screenshots/03-calibration.png)
*图 3-1：顶部为升降/头部点动按钮；下方左右两张表分别是左臂（can2）与右臂（can1）的关节标定状态。*

- **升降行**：`-5cm 下降` / `+5cm 上升` / `停止升降`，以及 `升降校准`、`头部校准`、`清除升降报警`。卡片顶部实时显示当前平台高度（如 `1.195 m`）与升降健康徽标（`升降正常`）。
- **头部行**：`左转 10°` / `右转 10°` / `抬头 10°` / `低头 10°` / `回中`。

操作要点：

1. 点动前确认工作区无人无障碍；
2. 升降接近行程上限（约 130 cm）时继续上升会被守卫拒绝——这是保护，不是故障；
3. 出现升降报警时先读报警文本，排除原因后再点「清除升降报警」；报警码含义与清理方法见售后手册。

## 关节标定：零位采集与应用

中部「关节标定」卡片负责双臂零位维护：

- **同步采集双臂零位**：把双臂摆到标定姿态后点它，一次性采集 14 个关节的零位候选；
- **保存并应用**：草稿确认无误后写入正式标定；
- **回滚上版**：应用后发现问题，一键回到上一版标定。

下方左右两张表是各臂 7 个关节的实时状态：**当前 raw**（电机原始角度）、**零位**（已应用标定值）、**端点**（`3/3` 表示该关节三端点数据齐全）。表值持续跳动说明数据链路健康。

## 选中关节面板：手动记录 / 电动微调 / 夹爪调试

点击表中任一关节（如 J1 肩部前后摆），中间出现「SELECTED JOINT」面板，含三个页签：

- **手动记录**：把关节手动摆到后摆/中位/前抬姿态，点「记录后摆」「记录中位」「记录前抬」采集端点候选 raw；
- **电动微调**：以极低速度小步长点动单个关节（受整组故障停止保护）；
- **夹爪调试**：切到该臂夹爪（通过 J8 选择左/右夹爪）。

## 夹爪调试：端点标定与开合控制

![夹爪调试页签：RAW 端点、开合滑杆与夹持力度](screenshots/03-calibration-gripper.png)
*图 3-2：夹爪调试页签。RAW 显示 `闭合 0xDC93 / 张开 0x216E`，端点齐全后即可用百分比开合。*

夹爪调试面板从上到下：

1. **RAW 端点显示**：当前 RAW、闭合 RAW、张开 RAW、当前开度（端点未齐时显示「—」）；
2. **记录闭合位置 / 记录张开位置**：分别在全闭、全开姿态各采一次端点；两端点齐全后网页自动显示标准化开合百分比，并保留 RAW 原始值；
3. **安全确认勾选**：「已确认工作区清洁，且 AC/DC 适配器断电开关可立即操作」——不勾选无法进行开合操作；
4. **开合滑杆**：0（闭合）~ 100（张开）拖动控制；
5. **夹持力度**：默认 20%（推荐），避免夹伤或过载；
6. **卸力**：立即释放夹爪持力。

## 动手试试

1. 在左右臂表中各点选一个关节，切换三个页签，熟悉手动记录与夹爪调试的入口（只看不点运动按钮，无风险）。
2. 拖动夹爪开合滑杆前，先完成安全勾选，再用小开度（如 30%）试一次，观察 RAW 与百分比同步变化。

## 小结

- 标定中心 = 整机点动 + 关节零位标定 + 夹爪端点标定，三者都有显式安全确认。
- 零位流程：同步采集 → 保存并应用 →（必要时）回滚上版。
- 夹爪端点齐全后以百分比开合，RAW 永远保留可追溯。
- 所有标定数据 fail-closed：数据缺失时显示「—」并拒绝相关操作，而不是猜一个值。
