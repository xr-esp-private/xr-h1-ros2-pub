# 第三章：标定中心

> **本章目标**：完成一次完整的关节端点记录流程（选关节 → 电动微调 → 记录端点），并掌握夹爪端点标定与开合控制；理解页面中所有"安全确认"的含义。
> **涉及文件**：`src/xr_arm_console/xr_arm_console/app.py`（标定接口）

标定中心从上到下三大功能区：**整机维护**（升降/头部点动）、**关节标定**（零位管理）、**双臂标定表 + 选中关节面板**。所有会真实运动的操作都有显式安全确认，未确认时按钮直接禁用——先学会看懂这些确认，再动手。

## 整机维护：升降与头部点动

![标定中心：整机维护按钮区与左右臂标定表](screenshots/03-calibration.png)
*图 3-1：顶部为升降/头部点动按钮，实时显示平台高度（1.195 m）与「升降正常」徽标；下方左右两张表分别是左臂（can2）与右臂（can1）。*

**升降行操作**（`-5cm 下降` / `+5cm 上升` / `停止升降`）：

1. 确认工作区无人无障碍；
2. 点 `-5cm` 或 `+5cm`，平台即向目标高度运动，卡片实时刷新「实际/目标」高度；
3. 任意时刻可点红色 **停止升降** 急停；
4. 平台接近行程上限（约 130 cm）继续上升会被守卫拒绝——这是保护，不是故障。

**头部行操作**：`左转/右转 10°`、`抬头/低头 10°`、`回中`，点按即动，幅度固定小步长。

**维护按钮**：`升降校准`、`头部校准`、`清除升降报警`。出现升降报警时**先读报警文本**（卡片顶部有完整文字，如历史报警码），排除原因后再清除；报警码含义见售后手册。

## 关节标定：从选关节到记录端点

中部「关节标定」卡片负责双臂零位与端点管理，右上三个全局按钮：

- **同步采集双臂零位**：双臂摆到标定姿态后点它，一次采集 14 个关节零位候选；
- **保存并应用**：草稿确认无误后写入正式标定；
- **回滚上版**：应用后有问题，一键回到上一版。

**分步操作：记录一个关节的端点**

**第 1 步**：在左/右臂表中点击目标关节行（本例选左臂 `J2 肩部开合`）。行高亮，中间出现「SELECTED JOINT」面板：

![选中 J2 后的关节面板：手动记录页签显示当前 raw 与三个姿态候选位](screenshots/03-joint-selected.png)
*图 3-2：选中 J2 肩部开合。面板顶部三个页签（手动记录/电动微调/夹爪调试）；手动记录页显示「当前 raw 0.0002 状态新鲜·已稳定」和三个候选端点（内收夹紧 -0.2657 / 中立位 -0.0010 / 外展抬起 3.1619），下方是对应的「记录」按钮。注意每个候选都有"候选 raw · 草稿状态·未应用"字样——记录只是写草稿，必须再点「保存并应用」才生效。*

**第 2 步**：把关节摆到目标姿态。两种方式：

- **手动摆**：断电状态下用手摆到位置（raw 会实时跟随显示）；
- **电动微调**（推荐，见下节）。

**第 3 步**：姿态到位后点对应「记录」按钮（如 `记录外展抬起`），该候选位刷新为新 raw，草稿状态变为「候选完整」。

**第 4 步**：所有端点记录完 → 点顶部 **保存并应用** → 表格中「零位/端点」列更新。有问题的点 **回滚上版**。

## 电动微调：低速点动单关节

![电动微调页签：步长/速度/扭矩参数与安全确认](screenshots/03-electric-trim.png)
*图 3-3：电动微调页签。可调微调步长（1.00°）、微调速度（5.0°/s）、额定扭矩（15 Nm·推荐）；注意底部蓝色按钮此时显示「请先勾选安全确认」——安全确认未勾选时运动按钮是禁用的，这是页面的 fail-closed 设计。*

操作步骤：

1. 切到「电动微调」页签，按需调小步长/速度（首次操作建议 1° / 5°/s）；
2. 勾选「工作区已清空，AC/DC 断电开关可立即操作」——勾选后运动按钮才可用；
3. 选动作方向（后摆/前抬），点按进行微调；「立即停止」随时可按；
4. 面板实时显示速度、力矩、温度反馈；勾选「控制后持续保持」可让关节在微调后保持力矩（仅显式卸力或故障释放）。

## 夹爪调试：端点标定与开合控制

点击关节表中 J8（或通过选中关节面板的「夹爪调试」页签）进入：

![夹爪调试页签：RAW 端点、开合滑杆与夹持力度](screenshots/03-calibration-gripper.png)
*图 3-4：夹爪调试。RAW 显示闭合 0xDC93 / 张开 0x216E，端点齐全后可用百分比开合。*

**端点标定（首次使用夹爪前做一次）**：

1. 点「记录闭合位置」——夹爪处于全闭姿态时采集；
2. 点「记录张开位置」——全开姿态时采集；顶部「端点齐全」徽标点亮；
3. 之后开合显示自动切换为 0~100% 标准化百分比，RAW 原始值永远保留可追溯。

**日常开合**：

1. 勾选「已确认工作区清洁，且 AC/DC 适配器断电开关可立即操作」；
2. 拖动开合滑杆（0 = 闭合，100 = 张开），夹爪即动；
3. 「夹持力度」默认 20%（推荐），夹易碎物品可再调低；
4. **卸力**按钮立即释放夹爪持力。

## 动手试试

1. 选一个关节切到「电动微调」，先**不勾**安全确认，观察运动按钮禁用并显示「请先勾选安全确认」；再勾选后用 1° 步长点一下，观察角度表变化。
2. 在手动记录页把 J2 摆到一个新姿态点「记录」，看到「草稿状态：候选完整 · 未应用」后点「保存并应用」，对比表格零位/端点列前后变化。

## 小结

- 标定中心 = 整机点动 + 关节零位/端点标定 + 夹爪端点标定，全部带显式安全确认，未确认按钮禁用。
- 记录端点四步：选关节 → 摆姿态（手动/电动微调）→ 记录草稿 → 保存并应用（可回滚）。
- 夹爪端点齐全后以百分比开合，RAW 永远保留。
- 所有标定数据 fail-closed：数据缺失显示「—」并拒绝相关操作，绝不猜值。
