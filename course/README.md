# XR-AIH1 机器人控制台使用教程

> 一句话课程简介：读完本课程，你将学会使用浏览器控制台（`http://<机器人IP>:8088`）完成 XR-AIH1 整机的日常操作——查看双臂状态、相机预览、升降与头部控制、建图导航、示教录制、工作流编排，并掌握可供二次开发的 HTTP API 与 ROS 话题。

**适合读者**：购机客户、现场操作员、售后工程师，以及需要对接机器人做二次开发的集成商。
**前置要求**：

- 一台与机器人处于同一局域网的电脑（浏览器推荐 Chrome / Edge）；
- 知道机器人的 IP 地址（下文以 `<机器人IP>` 指代）；
- 进阶章节（第 7、8 章）需要会使用 `curl` 或任意 HTTP 客户端，了解 ROS 2 基础概念更有帮助。

## 如何访问控制台

机器人开机并联网后，直接在浏览器打开：

```text
http://<机器人IP>:8088
```

无需安装任何软件。页面右上角的「链路在线」徽标为绿色即表示数据链路正常。

## 安全须知（务必先读）

1. **默认只读**：控制台默认只做状态采集，不会使能电机、不会自动回零。所有会真实运动的操作都需要显式确认。
2. **运动三件套**：所有身体运动类 API（升降、头部）强制要求「产品门控 + 意图请求头 + `confirm:true`」，缺一即被拒绝——这是设计使然，不是故障。
3. **现场安全优先**：执行任何升降、头部、双臂运动前，确认工作区无人员与障碍物，AC/DC 适配器断电开关处于可立即操作的位置。
4. **3D 模型视图只用于展示**：3D 展示与关节模拟不发送真实指令、不作为安全依据。
